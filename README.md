# Tampermonkey Userscripts

A collection of userscripts for [Tampermonkey](https://www.tampermonkey.net/).

## Scripts

| Script | Description |
|--------|-------------|
| [marketsurge-chart-fixes](marketsurge-chart-fixes/) | Fix chart scaling issues on MarketSurge weekly and daily views |
| [tradingview-hlc-bar-enhancements](tradingview-hlc-bar-enhancements/) | Enhance HLC bars: adjustable thickness and StockCharts-style close ticks on both sides |
| [volumeleaders-chart-fixes](volumeleaders/) | Fix Volume-Based bubble sizing corrupting the X-axis and auto-select it on page load |
| [volumeleaders-chart-height-fix](volumeleaders/) | Fix chart not filling its container due to stale height config in localStorage |

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) for your browser
2. Navigate to the script you want
3. Click on the `.user.js` file
4. Click "Install" when prompted
