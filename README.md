# Tampermonkey Userscripts

A collection of userscripts for [Tampermonkey](https://www.tampermonkey.net/).

## Scripts

| Script | Description |
|--------|-------------|
| [tradingview-thicker-bars](tradingview-thicker-bars/) | Keep OHLC bars visually thick when zoomed out on TradingView charts |

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) for your browser
2. Navigate to the script you want
3. Click on the `.user.js` file
4. Click "Install" when prompted
